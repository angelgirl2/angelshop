# Legacy Worker (KV)

این پوشه نسخه قبلی Worker مبتنی بر KV است و فقط برای مرجع/بازیابی حفظ شده است. فایل‌ها و شناسه KV آن عمداً در بسته باقی مانده‌اند، اما **نباید این Worker را برای نسخه تولیدی جدید deploy کنید**.

استقرار فعال در پوشه `../cloudflare-production/` است و از یک Worker و D1 مستقل استفاده می‌کند. هیچ کد یا دیتابیسی در Worker قدیمی حذف یا تغییر داده نشده است.
